- **Structure**: HTML5 (Semantic Markup)
- **Styling**: Vanilla CSS3 (Custom Properties, Glassmorphism `backdrop-filter`, Keyframe Animations)
- **Logic & Interactivity**: Vanilla JavaScript (ES6+, IntersectionObserver, Clipboard API, DOM Manipulation)
- **Icons & Typography**: FontAwesome 6.5, Google Fonts (*Plus Jakarta Sans*, *Inter*, *Fira Code*)

## 🚀 **Local Setup & Usage**

Clone the repository and open `index.html` in any modern web browser or serve locally:

```bash
# 1. Clone the repository
git clone https://github.com/logamoorthy-2006/portfolio-logamoorthy.git

# 2. Navigate into the directory
cd portfolio-logamoorthy

# 3. Serve locally using npx or Python
npx serve .
# OR
python -m http.server 5050
```

Open your browser at `http://localhost:5050` (or `http://localhost:3000`).
